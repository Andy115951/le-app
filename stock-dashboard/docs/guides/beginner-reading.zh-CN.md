# 新人解读

[English](./beginner-reading.md) | 简体中文

## 它是什么

新人解读是用户手动请求的说明，用来串联看板上已经展示的事实。它帮助刚开始关注市场的用户理解某个市场日，但不会隐藏高级研究视图。

确定性解读固定包含五段：

1. 纳指基准与已观察到的波动环境。
2. 核心股票相对 QQQ 的表现。
3. 公开新闻与财报日历背景。
4. 已成熟的历史对照样本，如有。
5. 用户自己设置的观察条件，如有。

## 如何使用

1. 打开首页或某个带日期的市场日视图。
2. 选择“读一下今天”或对应日期的操作。
3. 查看生成的事实段落，并在看板中核对相应来源。
4. 若已启用可选模型解读，选择“生成 AI 解读”，再明确确认请求。

只有操作后才会生成解读。刷新行情或打开页面不会静默生成内容。

## 模型解读边界

可选模型解读是五段事实下方的独立层。它不是新的市场数据，也不会替代来源材料。

- 确认后，只会发送页面展示的五段事实供模型讲解。
- 持仓数量和成本不会进入该请求。
- 功能关闭、服务不可用或校验拒绝时，确定性解读仍然可用。
- 实现会拒绝交易指令、目标价、概率判断和不受支持的因果表述。

## 正确理解结果

- 带链接的新闻只是需要核对的证据，不证明它造成了价格变化。
- 历史结果描述已完成样本，不是对当前市场日的预测。
- 预定财报日是日历事实，不是当前涨跌的解释。
- 缺失数据会保持缺失，解读不会猜测替代数值或原因。

新人解读用于学习和理解，不构成投资建议。
