# 只读界面 QA

[English](./README.md) | 简体中文

在 `ledger/` 运行 `npm run ui:qa:build`，再运行 `npm run ui:qa`，打开本机回环地址 `http://127.0.0.1:4188/`，用窄屏浏览器检查响应式布局。服务只提供本应用生成的 `dist/`，仅接受 GET / HEAD，没有账本或写入接口。

此入口使用固定虚构样例（三个账户、一条盘点），渲染正式的 `LedgerApp`、字体、主题、小金库和隐私控件。界面仓储为只读，拒绝全部财务写入与恢复；不会调用 `openLedger`、打开 SQLite 或连接桌面 IPC。字体、小金库外观与资产数字显示偏好只属于此浏览器来源。QA 入口独立于正式客户端，不会进入普通 Android 或桌面构建。

可检查布局、鼠标 / 键盘交互、隐藏文字与 DOM、弹窗及页面切换；不能替代 Tauri 存储、Android 原生触摸取消、系统键盘、系统后台快照及原生无障碍验收。这些仍需使用合成数据另行验证。用户工作时保持浏览器后台测试，桌面原生鼠标 / 键盘交互仍需要焦点。
