# 记账产品官网

[English](./README.md) | 简体中文

智账（Android）／简账（桌面端）的独立静态中文官网，介绍本地记账、账户、自然光金库、手动局域网传输、平台支持和隐私。全部账户、余额和流水均为虚构数据。手机演示只改变当前页面内存，刷新即重置。官网不导入客户端、不打开 SQLite、不读取账本导出、不请求相机权限，也不执行真实传输。

在此目录使用 Node 22+ 运行 `npm run check`、`npm run build`，再运行 `npm run dev`，通过 `http://127.0.0.1:4190/` 预览。不需要安装依赖或配置秘密环境变量。可将 `dist/` 部署到静态托管平台。`build.mjs` 仅复制明确列出的网站 HTML／CSS／JS 与 `assets/`，不打包周围的记账 workspace、原生产物、记录或安装包。托管标识和凭据不进入公开源码。

应用获取弹窗明确说明安装包尚未公开发布，提供真实公开项目／安装说明链接，不使用无法工作的下载按钮。安装包公开发布属于另行明确授权的发布步骤，发布前检查二进制隐私、签名、平台支持和源码来源。

保险柜与黄金 WebP 由项目已有生成素材转换；字体为内置 600 字重 Noto Serif SC 与 Libre Baskerville 派生字体的改名 WOFF2 子集，随附两份 OFL 许可。源码不使用专有字体、用户截图、远程字体或统计 SDK，图标沿用既有 SVG。VibeDrop 会在托管页加入访问统计与托管标识，隐私弹窗已说明。

浏览器检查覆盖桌面和窄屏布局、无横向溢出、面额边界、柜体升级、试记金额计算、金额／金库独立眼睛、传输方向示意、FAQ 展开、平台说明弹窗及隐私说明。交互调整时保留减少动态效果偏好、键盘焦点和无障碍标签。传输图只演示流程，不建立连接；应用 JSON 导出和存储沿用既有未做静态加密的行为。

构建后可用 `npm exec --yes --package=@vibedrop/cli@0.3.0 -- vibedrop deploy ./dist --unlisted --title "智账 · 把生活记清楚"` 部署 VibeDrop 链接预览。后续更新追加 `--slug EXISTING_SLUG`，使用服务返回的标识以保持网址不变。仅部署 `dist/`，不能上传记账 workspace 或安装包。知道链接的人均可访问，不需要 OpenAI 登录，也不会提交到 Explore／搜索；是否到期以服务返回值为准，不能视为永久地址。CLI 凭据留在用户目录、仓库之外；已忽略的 `.openai/vibedrop.json` 可保存不含密钥的部署信息。参见[官方 CLI 说明](https://vibedrop.cc/skill.md)。
