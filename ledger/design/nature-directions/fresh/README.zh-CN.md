# 简账视觉草稿 — 02

[English](./README.md) | 简体中文

打开 [index.html](./index.html)，可查看五个页面、悬浮底栏、操作弹窗和桌面布局。单屏模式可切换页面，五页对照模式并排展示完整页面。

底色选择可比较白底（当前默认项）与之前的浅绿版。白底去掉总览的大面积绿色区域，正文与导航底色转为中性色，绿色保留在主要操作与选中态。字体选择、悬浮底栏均保留。切换也会更新已打开的弹窗，不重置输入。可用 `tone=white` 或 `tone=green` 查询参数指定初始底色。

已在输入金额并打开账户选择弹窗后检查白底 / 浅绿切换：金额、字体选择与弹窗状态均保留，白底弹窗使用白色面板。375 像素宽度下五页均无横向溢出。当前白底预览为 `previews/white-overview-details-entry.jpg`，先前绿色截图保留用于对比。

字体工具栏可比较三种组合：全无衬线、宋体标题搭配无衬线数字、宋体标题搭配 Georgia 衬线数字（接近旧版，本次评审默认项）。正文保持系统无衬线字体。切换会同时更新页面和已打开的弹窗，不重置演示输入或滚动位置。可用 `font=sans`、`font=mixed` 或 `font=book` 查询参数指定初始组合。预览暂用平台字体回退，尚未打包跨端字体文件。

这是一份独立的 HTML / SVG 设计稿，参考 [Gentler Streak](https://gentlerstories.com/gentlerstreak) 柔和的色彩层级与 [Dime](https://apps.apple.com/us/app/dime-budget-expense-tracker/id1635280255) 简洁的数字和列表排版，没有复制参考产品的素材、品牌或源码。字体使用系统回退，无需外部素材或依赖。

所有账户、金额、流水和日期都是虚构内容。十月示例收入为 12,000.00，支出为 2,460.00，结余为 9,540.00。资产 49,480.00，负债 800.00，净资产为 48,680.00。八笔示例流水与显示的月度统计一致。

搜索、筛选、账户选择、可选标签、改名和盘点使用临时演示状态。保存、导出和导入只展示操作方式，不读写账本、数据库、浏览器存储、文件或网络服务。刷新后演示状态重置。已选定的白底 / 书卷方案正在接入正式 React Native 客户端，此 HTML 仍是独立参考。实现状态、内置字体与原生验收见[开发说明](../../../docs/DEVELOPMENT.zh-CN.md)及[验证记录](../../../docs/VERIFICATION.zh-CN.md)。

这是一份视觉评审草稿，不是正式实现或完整的无障碍规范。创建账户和修改流水只展示操作面板，没有实现账本变更。真实记账与字体偏好由共享应用实现，不放在这个演示中。

浏览器检查覆盖五页对照、桌面总览与 375 像素宽度的手机布局；已核对工资搜索、收入筛选、账户选择回填、标签不选和演示保存提示。小屏记账页的保存按钮位于悬浮底栏上方，没有横向溢出。静态预览保存在 `previews/`。

字体检查覆盖三种组合及已打开的账户选择弹窗。切换后金额和备注保留，弹窗保持打开且标题字体同步变化。衬线数字组合在 375 像素宽度下五页均无横向溢出，保存按钮仍在底栏上方。`previews/typography-book.jpg` 展示该组合。
