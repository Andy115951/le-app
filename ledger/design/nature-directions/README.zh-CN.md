# 自然系视觉探索

[English](./README.md) | 简体中文

后续的[绿色清新版草稿 — 02](./fresh/index.html) 参考 Gentler Streak 与 Dime，将悬浮底栏、五个页面与操作弹窗统一成一套方向。下面的三套原始方案保留用于对比。

用浏览器打开[交互稿](./index.html)。三套绿色方向均可切换总览、明细、记一笔、资产、设置，还支持单独查看与桌面布局。财务内容全部为虚构数据；输入与导航仅在内存中演示，不读写真实账本。

工具栏可将手机底栏切换为「贴底」或「悬浮」。悬浮底栏四周留空，底部内容仍可滚动查看；桌面保持侧栏导航。

- **林间留白**：浅绿、无衬线排版、小幅页首风景。
- **雾岸油画**：灰白纸色、苔绿、宋体标题与衬线数字，总览保留油画风景。
- **森绿手账**：暖色纸张、橄榄绿墨色、直线分区、小幅风景插页。

这是一组独立设计稿，没有修改正式 React Native、数据库或 CLI 代码。中文宋体与手账感标题暂用平台字体回退，选定方向后仍需确定最终的跨端字体方案。

三套的差异覆盖风景之外的界面：记账字段、金额底色、可选标签、数字键盘、保存按钮、明细分组、账户展示、设置行、导航与操作面板都分别处理。可以点开账户选择、账户编辑、理财盘点、标签编辑或导入预览。账户选择只回填演示表单，确认面板不会执行财务操作。

另有可编辑的 Figma 设计稿，包含三套总览，以及推荐方向的四个内页和账户选择、理财盘点、账户编辑、导入确认面板。其中使用 Noto Sans SC 与 Noto Serif SC；HTML 交互稿使用对应字体类别的平台本地回退。

`assets/mist-lake.png` 为使用内置图像生成工具创作的独立风景素材。用户提供的游戏截图只用于文字描述氛围，没有复制进项目或上传到 Figma。风景本身是图片，界面文字、图标、金额和控件仍是 HTML / SVG。

生成提示词：

> 为安静的个人记账工具创作原创横向油画 / 水粉风景：苔绿与黄绿色树木围绕灰白湖面，远岸隐入银白雾气，极少量橙褐色秋叶。清新的秋日晨光，有层次的绘画笔触与轻微画布纹理。中央留出灰白空间，绿树与白桦树干主要位于两侧。不要文字、UI、标志、水印、画框、幻想或游戏元素。

也可通过本机静态服务器预览。本交互稿不需要构建、外部 CDN、凭据、账号或网络服务。
