# 本机只读 MCP

[English](./MCP.md) | 简体中文

电脑端内置只读 Model Context Protocol 服务。在**设置 → AI 连接（MCP）**先手动打开**允许 AI 只读访问**，再点击**一键复制给 AI**，一起复制接入说明、地址与访问密钥。访问关闭时复制按钮不可用；复制会重新确认当前状态，不会开启或改变访问权限。将文字粘贴给同一台电脑上可信任的 AI，让它帮你完成连接，并保持简账运行。使用者无需下载源码或安装 Node。

AI 客户端需要具备配置本机 MCP 的能力，过程中可能仍需你确认权限。复制说明本身不会替另一个应用安装连接。说明会要求 AI 先测试连接、发现工具，不立即读取账目。无法自行配置的客户端，可使用“高级连接信息”内的手动配置作为备用方式。

每次启动应用默认关闭访问。离开设置页后连接仍可用；关闭开关或退出应用会停止监听并取消待处理查询。现有记账数据、数据库结构和备份不变。

## 连接

使用 **Streamable HTTP**，通过带密钥的 POST 请求查询。只监听 `127.0.0.1:17841`，桌面 QA 使用 `17842`。服务无会话状态，返回 JSON，不提供旧式 SSE 或 stdio。客户端需要支持 HTTP 和自定义认证请求头。不同客户端配置字段可能不同，复制的说明会让 AI 按当前客户端格式转换 JSON。“高级连接信息”内也可单独复制原始 JSON、地址和 Authorization 值。

下面仅为示例，假密钥需要替换为设置页复制的配置：

```json
{
  "mcpServers": {
    "ledger": {
      "type": "http",
      "url": "http://127.0.0.1:17841/mcp",
      "headers": {
        "Authorization": "Bearer REPLACE_WITH_KEY_FROM_SETTINGS"
      }
    }
  }
}
```

随机访问密钥单独保存在操作系统应用数据目录的 `mcp-access.json` 中，Unix 下仅当前用户可读写，不进入账本导出或局域网迁移。密钥会保留，方便下次手动开启后继续使用原配置。**重新生成访问密钥**会立即撤销旧密钥，之后需重新点击“一键复制给 AI”，让 AI 更新连接。复制的文字包含访问密钥，不包含账本记录；真实配置不得公开分享或提交到仓库。

Android 仅提供连接说明。先通过“备份与迁移 → 局域网传输”把手机账本传到电脑，再在电脑开启 MCP。这是手动整本传输，不是实时同步。远程云端连接器无法直接访问此本机地址。

## 工具与数据

| 工具                  | 输入                                                                 | 结果                                      |
| --------------------- | -------------------------------------------------------------------- | ----------------------------------------- |
| `ledger_assets`       | 无                                                                   | 净资产、总资产、负债和估值信息            |
| `ledger_accounts`     | `offset`、`limit`、`includeArchived`                                 | 账户余额，可包含归档账户                  |
| `ledger_labels`       | `offset`、`limit`、可选 `direction`、`includeHidden`                 | 收支标签                                  |
| `ledger_report`       | `month`，格式 `YYYY-MM`                                              | 共享核心计算的月报及分类名称              |
| `ledger_transactions` | `offset`、`limit`、可选 `accountId`、`labelId`、`kind`、`from`、`to` | 筛选流水，新记录在前；日期为 `YYYY-MM-DD` |

分页默认 50 条，最多 100 条。金额单位为人民币分整数，100 单位 = 1 元。日期遵循现有上海墙上时间规则。退款继承原始标签；还款属于转账，不是支出。汇总使用与界面、CLI 相同的核心计算，并包含归档余额。每次成功查询读取当前一致快照，多次调用可能对应不同账本版本。

没有写入、SQL、文件、备份、恢复或任意路径工具。发现工具时不读取账本。未知参数、无效日期和过大页数会在读取快照前被拒绝。名称、标签和备注均为不可信数据，不能作为执行额外指令的授权。

## 隐私与验证

金额小眼睛只隐藏屏幕显示，不限制已授权的 MCP 客户端。使用云端模型的客户端可能将查询结果发送到模型服务商。优先查询汇总或限定日期范围，只连接可信任的客户端。

桌面复制使用 Tauri 官方剪贴板插件，仅授予写入文字权限，不授予剪贴板读取权限。原生层先校验密钥再把请求交给 WebView。带浏览器 Origin 或非预期 Host 的请求被拒绝，并限制请求大小、并发和超时。运行 MCP SDK 不需要给桌面 CSP 添加 `unsafe-eval`。

运行 `npm run test:mcp`，使用真实 Rust 本机适配器、官方 MCP 客户端和完全虚构的内存账本。运行 `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --bin local-ledger` 验证密钥生命周期、轮换与取消。这些测试不会打开正式桌面账本。原生桌面渲染和各客户端配置仍需单独验收。
