# 开发说明

[English](./DEVELOPMENT.md) | 简体中文

以下命令在 `ledger/` 运行。需要 Node 22.13+、npm；Android 需要 Android SDK 和 JDK 21；桌面需要 Rust 和对应系统的 Tauri 构建环境。这是独立的内部 npm workspace，不调整仓库其他应用。

```sh
npm ci
npm test
npm run typecheck
npm run start
npm run android
```

`npm run android:build` 在 `artifacts/ledger-0.1.0-test.apk` 生成 arm64 测试包，内置 JS，可脱离 Metro 和网络运行。其他架构通过 `LEDGER_ANDROID_ARCHS` 指定。原生目录自动生成并被忽略。生成的开发签名只供内部测试；对外发布前需配置私有正式签名。`adb -d install -r artifacts/ledger-0.1.0-test.apk` 只安装到实体设备，不选择模拟器。不能为验证新版本而清除已有用户的数据。

`npm run android:build:qa` 生成 `artifacts/ledger-0.1.0-qa.apk`，名称为 **智账 QA**，包名为 `app.local.ledger.qa`。它与普通版并列安装，Android 数据库和缓存互相隔离。整本恢复与分享测试只在此包中使用独立生成的合成文件，不能为了获得测试样本而导出 / 导入用户的普通账本。QA 与普通包切换时需重新 prebuild；生成的 application ID 与目标包不一致时，构建脚本会拒绝 `--skip-prebuild`。

```sh
npm run desktop
npm run build -w @ledger/desktop
npm run build:qa -w @ledger/desktop -- --bundles app
npm run windows:build
npm run check -w @ledger/desktop
npm run cli -- help
```

Windows x64 NSIS 打包与数据迁移见 [Windows 测试构建](./WINDOWS.zh-CN.md)。Windows 本机使用 MSVC 工具链，macOS／Linux 交叉编译使用 `cargo-xwin`、LLVM／LLD 与 NSIS；安装包和校验文件复制到已忽略的 `artifacts/windows/`。

桌面在 Tauri 中渲染同一套 RN Web 界面，使用 Rust SQLite。`export:web` 生成桌面资源，直接用普通浏览器打开不会创建另一份账本。Android 使用 Expo SQLite。CLI 和 Tauri 默认访问系统应用数据目录 `app.local.ledger` 下的同一个 `ledger.sqlite`：macOS 为 Application Support，Windows 为 Roaming AppData，Linux 为 XDG data。手机账本独立，通过 JSON 或手动局域网传输迁移。CLI 可用 `--db` 指定仓库外的合成测试数据库；这不会重定向桌面应用的数据库。

桌面 QA 配置生成 **简账 QA / `app.local.ledger.uiqa`**，使用独立应用数据目录，初始窗口设置 `focus:false`。示例中的 `--bundles app` 针对 macOS。构建、类型检查、CLI / 仓储测试及 ADB 不会激活 Mac 窗口；macOS 启动 QA 包时可用 `open -g -n`，同时请求应用在后台启动。桌面原生点击与键盘快捷键仍需前台交互，用户工作时暂缓；用户切离后不能反复激活 QA。Android 输入或截图前先确认 QA 包在前台，切离后停止，不能把其他应用的屏幕收作测试证据。

## 共享边界

- `packages/core`：无平台依赖的命令、校验、整数金额、余额、报表、版本化备份。
- `packages/storage`：SQLite v1、类型化 JSON 记录和乐观并发控制。Expo / Node / Tauri 驱动共用仓储。每次写入先拿数据库写锁，读取一致快照、检查版本、校验，再原子提交有变化的记录。
- `apps/client`：五页 RN 界面、原生文件选择/分享、导入预览和操作确认。
- `apps/desktop`：本地 Tauri 壳、SQLite 与文件对话框桥接，不载入远程内容。
- `apps/cli`：版本化 JSON 输入输出、最小范围查询、明确 `--commit` 和稳定错误码。

账户名称属于用户数据，不是系统翻译文案。在资产页点击账户名称 / 改名，可自行输入或选择常用中文名称。共享 `account.rename` 命令保留账户 ID、期初金额、余额和全部流水关联；应用不会自动替换用户填写的英文名称。

添加账户时，期初时间显示为“开始记账时间”，期初金额按类型显示为开始时的余额、总估值或欠款。默认从今天零点开始；如需补记更早的账，应选择更早的开始时间并填写当时的金额。已有金额不算新增收支。这些文案不会改变 `openedAt`、`openingMinor`、计算逻辑或已有记录。

五个页面共用接近白色的暖灰底、白色操作弹窗与悬浮底栏、深色文字和少量绿色点缀；总览在宽窗口使用双栏。Android 记账表单内置小数数字键盘，备注仍使用系统键盘，系统键盘打开时隐藏底栏。账户、标签与时间选择在窄屏使用底部弹窗，宽屏使用居中弹窗。财务命令与存储继续与 CLI 共用。

设置首页显示标签、外观、备份与迁移、变更记录、关于五个简洁入口；进入二级页后才渲染操作和列表。自动备份收在备份与迁移内，点击后才读取。字体选择收在“外观 → 字体”中，提供清爽、雅致、书卷三种方案，默认书卷。顶部返回按钮和 Android 返回键逐级返回，点击设置标签重新打开首页。明文备份说明与替换确认保留在对应操作处。

字体随应用打包，离线可用，来源与许可证位于 `apps/client/assets/fonts/`。可读性改版使用真实 600 字重的衬线轮廓、系统中等字重正文、13 号辅助文字与 12 号导航文字；主背景上的主 / 辅文字对比度约 13.7:1 / 6.1:1，白色、浅色和选中表面上的文字配色也均高于 4.5:1。已保存的字体选择保持不变。标题与金额可以使用内置衬线字体，正文仍使用系统字体，生僻字由平台字体补齐。字体偏好在 Android 使用独立的 Expo SQLite 键值存储，桌面使用 WebView 的 localStorage。切换字体不会修改财务记录、推进账本版本或进入 JSON 备份。字体加载失败时退回系统字体；关于页面可查看内置许可全文。

标签支持可选的内置 SVG `icon` 标识。旧记录缺少图标时只在显示时推断，不自动改写；界面编辑保存所选图标，旧 CLI 调用省略该字段时保留现有选择。JSON 格式 v1 与 SQLite 结构 v1 保持兼容，图标元数据随备份迁移。合法标识见 [CLI](./CLI.zh-CN.md)。

余额没有独立的权威缓存，均由期初、流水和盘点锚点计算。盘点表示**同一秒内全部流水发生后**的实际余额。补记更早的流水会改变收支报表，但不会改写之后观察到的余额；删除盘点可回到按流水推算。信用卡负余额表示欠款，正余额表示溢缴款。期初欠款和还款不计支出。退款使用原账户和标签，在退款月份冲减支出，累计不能超过原消费；删除原消费前需先删除退款。所有时间均为 `Asia/Shanghai` 墙上时间，不随设备时区变化。

每次成功命令记录幂等回执和来源（`ui` / `cli`）。重试使用同一操作 ID 和完全相同输入，返回原结果。写入需携带快照 token；其他修改或整本导入使旧 token 失效。修改和删除还需记录版本。应用重新获得焦点时刷新；提交旧快照时拒绝覆盖其他进程的新修改，无需后台轮询。写入失败保留当前表单。

导入先完整校验文件，再预览数量，确认时重新检查 token，将当前账本自动备份到 SQLite，然后在同一事务中整本替换。设置里可预览恢复自动备份，CLI 也可单独导出。重复导入只替换、不追加。导出包含当前本地操作/审计历史，不包含更早的自动备份。JSON 为**明文**，应用数据库也未做应用级加密；Android 系统云备份已关闭。数据库、导出和真实日志不进入 Git。

可选的自然光小金库位于设置 → 外观，未保存偏好时默认开启，保留已保存的关闭选择。它用计算后的净资产、内置离线 PNG 与 React Native SVG 渲染。独立本机键值偏好不进入账本 JSON。金库拥有独立于资产数字的眼睛和会话显示状态。隐藏时使用固定闭合柜体，移除等级与数量；金库内容在离开资产页或进入后台时重置，数字显示则沿用已保存的本机偏好。面额、门槛与原生验收限制见[小金库设计](./VAULT_DESIGN.zh-CN.md)。

总览与明细共用顶部的月份快捷选择器。点击日期打开十二个月网格，点击年份进入每页十二年的年份选择，也可以直接回到上海账本日期的本月。选中月份立即应用，未选中就关闭不会改变月份。窄屏用底部弹层，宽屏用居中弹窗。此为临时视图状态，不写财务记录或保存偏好；月份／年份导航限定于支持记账的 1900–2199 年。

## 验证与当前限制

没有保存选择时资产金额默认遮蔽。眼睛按钮将显示／隐藏状态保存为独立本机键值偏好，切换页面及重启后保留；不保存金额，也不进入账本或 JSON 备份。按住净资产区域 250 ms 后仍可临时查看，松手／取消隐藏临时内容，不改变保存的偏好。离开资产页仅取消临时查看；进入后台或桌面失焦时暂时遮蔽，返回后恢复已选状态。资产页以外的总览净资产仍遮蔽，收支金额保持原样。读取偏好失败时从隐藏开始；保存失败时保留本次会话选择并提示未保存。

净资产、总资产、负债、账户余额、账户弹窗余额、盘点金额 / 差额及盘点备注共用显示状态。隐藏时替换成固定四个圆点及对应无障碍标签，不通过模糊或透明度隐藏原文。盘点输入框在明确点击眼睛持续显示后才出现；隐藏时移除输入框，但保留组件内未保存的草稿。这是显示控制，不是数据库或备份加密。

`npm run ui:qa:build` 与 `npm run ui:qa` 提供适合后台测试的只读合成预览，用于桌面浏览器窄屏检查正式界面，范围见[界面 QA](../apps/ui-qa/README.zh-CN.md)。这是组件 / 界面测试环境，不能替代原生 Tauri / SQLite 集成或 Android 验收。

桌面样式初始化：`apps/client/public/index.html` 必须在应用脚本执行前包含空的 `react-native-stylesheet` 元素。Tauri 为已有样式元素添加每次响应专用的 CSP nonce，RN Web 复用这个已授权样式表；缺少它时，发行包中新建的无 nonce 样式元素会被拦截。桌面字体通过浏览器 FontFace API 读取已打包的资源 URL，避开在发行版 WKWebView 中超时的 Expo 样式表 / FontFaceObserver 路径；Android 继续使用 Expo Font。保留 CSP；每次桌面构建后检查文字、导航和弹窗的实际截图，仅有无障碍文本和数据库交互成功不足以验证显示效果。

`npm test` 覆盖转账修改/删除、信用卡还款/溢缴款、退款、盘点/补记、坏备份、幂等、双 SQLite 客户端、重启保留、模拟导入写入失败及 CLI 子进程。数据全部为合成示例。相关修改后运行类型检查、Android 导出和桌面 Web 导出。原生验收使用合成数据，覆盖建账户、收支、转账、修改/删除、盘点、重启及 JSON 导入导出。

当前实现限制：SQLite 每行存储类型化 JSON，暂未拆成规范化财务表；每次操作加载并校验整本账。适用于小型个人账本，不适用于超大导入或多人服务。数据库迁移使用 `PRAGMA user_version`，拒绝未知未来版本。暂无自动合并、静态加密、登录、云服务、自动行情或证券持仓。Windows / iOS 仍需各自原生验收；桌面打包、Android 交互验收与共享层测试分别记录。

依赖审计当前提示 Expo 开发 CLI 间接依赖的 Zod 3 存在公告。应用代码不导入 Zod；强制替换 Zod 4 会违背上游主版本约束。开发工具仅在本地使用，待上游兼容修复后复查，不运行会降级整个 SDK 的 `npm audit fix --force`。

局域网传输位于设置 → 备份与迁移，由桌面开启一次性加密服务、手机选择覆盖方向，沿用完整校验、token 检查与覆盖前自动备份的原子恢复。会话、协议与独立测试命令见[局域网传输](./LAN_TRANSFER.zh-CN.md)。
