# 局域网账本传输

[English](./LAN_TRANSFER.md) | 简体中文

两端打开 **设置 → 备份与迁移 → 局域网传输**。由桌面端（macOS 或 Windows）开启连接，Android 手机选择传输方向。接收方明确确认覆盖之前，两端保持各自账本。不需要账号或云端中转，不自动合并、后台同步或判断哪一端最新。

## 使用

1. 两台设备连接同一私有 IPv4 网络。桌面点击 **开启一次性连接**；系统询问局域网访问权限时允许本次连接。存在多个网卡时，选择手机可以访问的地址。
2. 手机扫描桌面二维码，或粘贴连接码后连接。打开扫码器后才请求相机权限；手动输入连接码无需相机。
3. 核对两端账本摘要，选择 **手机 → 桌面** 或 **桌面 → 手机**。桌面提供开启连接时捕获的快照；手机发送连接时展示的快照，期间本机账本有变化则拒绝发送。
4. 在接收设备核对待接收的数量，确认 **备份原账本并覆盖本机**。完整校验、接收方 token 检查、原账本备份及替换沿用既有 SQLite 恢复事务。接收方账本有变化时拒绝覆盖，关闭并重新连接以获取新预览。
5. 完成后再继续记账，并关闭连接。原账本可在 **自动备份** 中按 JSON 导入相同流程预览、恢复。更早的自动备份和本机外观／隐私偏好不随账本传输。

每次连接只接纳一台手机并传一整本账，十分钟后过期；桌面离开此页或退出应用会停止监听。手机离页会丢弃客户端状态，重新配对前请在桌面重新开启连接。传输中断不会自动替换账本。覆盖成功后的通知重试只重发完成通知，不再次执行恢复；通知无法送达时以接收方本机成功提示为准，下次传输前重新连接。

连接失败时检查所选桌面地址、两端网络、防火墙权限、访客 Wi-Fi 的设备隔离和连接码有效期。无需路由器端口转发。此实现不含纯 IPv6 网络、手机作为服务端、自动发现设备、普通浏览器作为服务端、iOS 验收或增量合并。

## 传输边界

桌面 Rust 原生监听器仅在连接开启期间使用临时端口。连接码包含随机 256 位密钥，通过扫码或粘贴交给另一端，授予本次会话读取所捕获账本的权限，仅交给目标设备。应用不会把连接码或密钥写入日志或财务存储。

HTTP 承载 AES-256-GCM 认证加密封包，不传明文备份。每个封包使用新的 96 位随机 nonce 和 128 位认证标签，请求和响应使用不同附加认证上下文。响应绑定请求 ID；服务端拒绝重放的请求 nonce、其他客户端 ID、更换传输 ID／方向、带浏览器 Origin 的请求、其他路径、分块请求和过大内容。请求头／正文限制及超时约束传入连接。配对密钥不会进入 HTTP 请求头、URL 或正文；Android 使用 Expo Crypto，桌面使用 RustCrypto。单独导出的 JSON 文件及 SQLite 存储沿用既有未做静态加密的行为。

桌面备份大小上限为 20 MB，加密封包上限为 28.1 MB。服务端先检查容器格式再暂存，接收方写入前由共用核心完整校验。监听器不打开数据库，也不调用恢复；只有接收方界面可以提交替换。

## 验证

在 `ledger/` 运行 `npm test`、`npm run typecheck`、`npm run test:lan` 和 `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --bin local-ledger`。集成测试仅绑定回环地址，使用生成的内存账本，验证真实 Rust HTTP 与 TypeScript 双向加密互通、确认前不写入、原账本可恢复、重试、取消、旧 token 保护、认证重放／反射拒绝及关闭监听。单元检查覆盖坏连接码、响应 ID 不匹配、加密篡改、过期与大小限制。

原生验收使用独立 QA 构建。不能为获得测试样本而导出、替换或检查普通用户账本。Android 相机／原生 AES 互通、实体设备 Wi-Fi 和防火墙行为仍需连接设备验证；仅编译和回环测试不足以证明这些路径。
