# 小金库

简体中文 | [English](./VAULT_DESIGN.md)

状态：已确认的自然光方向已接入共用正式客户端。之前的独立 HTML 草稿保留为设计历史，仅使用虚构金额。随附字体保留 SIL OFL 许可文件。

## 正式接入 — 2026-10-29

资产页根据当前计算的净资产渲染 `LittleVault`。React Native SVG 组合内置柜体素材、六格自然光黄金素材、接触阴影与层架，无需网络请求或新增财务存储。金额保持整数分。柜体门槛为 10 万元和 100 万元，随当前金额双向切换。零和负值显示空的小柜，负值保留带符号的净资产数字及说明。大额以有限素材展示，并明确完整数量。

设置 → 外观 → 小金库是独立的本机开关，未保存偏好时默认开启，保留手动保存的关闭选择。键值偏好与字体、账本及 JSON 备份分开保存；保存失败时保留原设置并提示重试。已有字体偏好兼容。隐藏金额时卸载随金额变化的场景、等级、数量说明和无障碍标签，替换为固定尺寸的闭合柜体。金库拥有自己的眼睛按钮和会话显示状态，与资产数字独立。金库初始隐藏，离开资产页或进入后台时重置。资产数字会在切换页面及重启后记住本机选择；后台／失焦时临时隐藏，不清除选择。只打开金库会显示数量和等级，资产数字仍保持遮蔽。

TypeScript 及 14 项测试通过，涵盖整数分边界、等级变化、大额有限展示和固定隐藏输出。Android/Hermes 与桌面 Web 导出均包含离线素材，普通 Android 测试 APK 构建成功。只读合成数据正式界面预览通过宽屏和 390 像素布局、初始关闭、开启并重载保留、隐藏后 DOM 不残留金额或等级标签、离页再进入恢复隐藏。Android 原生渲染／触摸／后台验收以及桌面打包后的视觉验收仍待进行。随后按明确授权对普通 Android 包执行覆盖更新，核对包名／签名兼容、安装／数据目录标识保留和应用启动，未读取或写入财务记录。细致的聚合与升级动画继续延后。

## 已确认的映射

| 金额              | 表现           |
| ----------------- | -------------- |
| 10,000 元         | 一块金块       |
| 1,000 元          | 一枚金币       |
| 100 元            | 一颗金粒       |
| 不足 100 元的零头 | 数量可变的金粉 |

这是固定的视觉面额，与真实金价无关。例如虚构的 12,345 元，拆成一块金块、两枚金币、三颗金粒和对应 45 元的金粉。按整数分拆分，保留不足一元的零头。金粉面积和粒子数量随零头变化；极小差异无法逐一肉眼分辨，准确数字始终是依据。

## 展示与控制

- 以净资产作为可视化依据，保留准确净资产、总资产、总负债与账户列表。
- **设置 → 外观 → 小金库**提供独立开关，正式版默认开启，除非手动关闭。草稿为了查看效果默认开启。此设置只改变展示方式。
- 金额与金库内容使用各自独立的小眼睛。金库隐藏时，无论数字是否显示，都使用固定闭合柜体，不展示面额数量或随金额变化的内容。金额仍支持按住临时查看，仅金库在离页或进入后台时重置；资产数字在返回资产页时恢复已保存的本机选择。
- 大额使用有限数量的金块叠放，并标明实际金块总数，不表达容量上限，也不改变已确认面额。最新成长草稿按柜体分别最多展示 9、30 或 48 块金块，并明确说明其余金块收在内层。
- 零资产和负净资产展示空金库，负值附明确说明，净资产数字保留正负号。
- 草稿支持输入金额、虚构预设、增减金额、面额进位和外观开关，不写入财务记录，也不保存偏好。

## 动效与评审

### 质感草稿 05

下一版绘制草稿针对贴图感调整，不改变面额、门槛或财务数据。使用独立六格素材：三种接近同尺寸的金块纹理、平放金币、倚靠金币与金粒。通过接触阴影、统一光照、稳定的轻微错位和内腔裁切，让物件融入柜内。少量物件集中摆放，层架区分顶面与前沿。它仍是 2D 组合，不包含物理光照模拟或完整 3D 遮挡。

预览提供同金额、同柜体大小的“原版 / 自然光版”切换、并排材质比较，以及 45 / 135 元预设。浏览器已确认：前者仅金粉，后者为一颗金粒加 35 元金粉；切换质感保留 135 元；128,888.88 元仍绘制 12 块金块、8 枚金币与 8 颗金粒。2026-10-29 已完成并排截图复核：自然光版的高光更收敛、金币平放成堆，与层架的接触更自然；仍能看出金块轮廓的重复。当前为已复核草稿，等待用户确认视觉效果。未接正式应用，也未访问用户记录。

### 成长草稿 04 — 当前方向

保险柜改为正视用户。柜体与黄金分成不同图层，切换金额会改变实际绘制的物件数量，不再使用固定的整幅静物图。先提供三个暂定档位供比较：

| 净资产                   | 柜体                         |
| ------------------------ | ---------------------------- |
| 10 万元以下              | 低矮暖白小型柜               |
| 10 万元起、不足 100 万元 | 更大的加固柜、黄铜内框与层架 |
| 100 万元及以上           | 灰绿钢制金库与更多收纳层架   |

门槛是草稿选择。当前按净资产双向切换，不保留历史最高等级。在固定 330 单位的画布里，所有等级使用相同的 36 单位金块素材、24 单位金币与 14 单位金粒；前两个档位内柜体也会随金额缓慢扩展，跨门槛再改变结构；金块不会逐渐缩小。手机视图只收掉小型柜上方未使用的空间，不改变画布横向比例。成长对比图保持底部对齐，让大小变化可见。

负净资产显示空的小型柜，金额保留负号；零资产同样为空。隐藏金额时，一并移除柜体、等级、内容与数量，使用固定大小的占位。独立展示开关和金额控制都只属于临时、虚构的预览状态。超过三个视觉档位的大额仍显示准确总数，并明确标注画面仅展示部分物件，不构成财务容量限制。更多档位与最终门槛规则仍待设计确认。

浏览器已检查 99.99 / 100 元、99,980 加 20 元、999,980 加 20 元、升级时金块尺寸不变、大额展示说明、隐藏行为、独立开关与窄屏溢出。均属于草稿检查，未接正式版、未更新手机，也未访问用户记录。短暂出现动画尚不包含完整的聚合与柜体升级动效。

### 之前的风格研究

视觉稿 03 使用绘画质感的暖白保险柜、灰绿内衬、打开的轮盘柜门与集中摆放的金子。此前否定的是第一版保险柜的具体画法，并非保险柜形态本身。03 仍为静态插画，后续成长草稿已将柜体和黄金拆成独立图层。

第一版具象保险柜插画因外观不理想而被否定。第二版视觉稿对比暖白陶盘与自然光金子、浅木盒与绘画质感金子，两种透明 AI 插画放在同一套资产页版式中，缩小插画占用空间，将面额说明收成一行。两版均已提供并排和单版查看。本轮是静态风格比较，虚构的 12,345 元组合不会随流水变化。正式实现前，需要将物件与容器拆成可复用素材，再接入金额驱动的排布与动效。生成的风格稿尚未加入正式应用。

原交互草稿对变化的物件组和金粉做短暂动画，尚未实现粒子实际聚合或金币熔成金块的形变动画。遵循系统减少动态效果偏好。接入正式版之前，先查看插画比例、金粉变化是否明显、物件摆放、大额叠放与窄屏占用空间。

浏览器已检查 99.99 / 100 元边界、9,990 加 20 元的进位、百万元叠放、零值与负值、金额隐藏和独立设置开关。窄屏没有横向溢出。这些是草稿验证，不代替安卓或正式应用验收。
